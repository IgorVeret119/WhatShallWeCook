# What Shall We Cook?

Приложение для поиска рецептов по названию, ингредиентам и целевым калориям, белкам, жирам и углеводам (КБЖУ). Оно запускается на вашем компьютере и открывается в браузере. Регистрация и ключи API не нужны.

## Быстрый запуск

1. На GitHub выберите **Code → Download ZIP** и распакуйте архив. Если пользуетесь Git, можно клонировать репозиторий.
2. Установите **Python 3.10 или новее** и откройте терминал в папке, где находится `server.py`.
3. При первом запуске импортируйте рецепты. Если файла `recipes.csv` ещё нет, команда скачает его. Понадобится интернет, размер файла — около 700 МБ.

   ```sh
   python tools/dataset.py
   ```

   Если у вас уже есть `recipes.csv` из набора **Food.com Recipes and Reviews**, положите его рядом с `server.py` и выполните ту же команду. Чтобы использовать файл из другой папки, укажите путь: `python tools/dataset.py --csv "путь/к/recipes.csv"`.

4. После завершения импорта запустите приложение:

   ```sh
   python server.py
   ```

5. Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000) в браузере. Чтобы остановить приложение, нажмите **Ctrl+C** в терминале.

Если команда `python` недоступна, попробуйте `py` на Windows или `python3` на macOS и Linux. Основному приложению не нужны сторонние пакеты. При следующем запуске достаточно выполнить `python server.py`.

## Как пользоваться

- Введите название блюда или ингредиент, например «курица» или `chicken soup`.
- Задайте КБЖУ на порцию ползунками. Ближайшие к цели рецепты появятся выше. Подбор по КБЖУ можно отключить.
- Нажмите на сердечко в карточке, чтобы сохранить рецепт в разделе **Любимые блюда**. Значки вверху открывают списки любимых и исключённых продуктов.
- В карточке нажмите **Выбрать и настроить КБЖУ**, чтобы изменить порцию и увидеть обновлённый состав. Можно уточнить массу ингредиентов и разрешить подбор добавок.
- Переключайте **Русский / English** в верхней части страницы. Рецепты без русского перевода будут показаны на английском.

Расчёт КБЖУ ориентировочный. У некоторых рецептов нет фотографий или точных масс ингредиентов. Исключение продуктов работает по названиям ингредиентов.

<details>
<summary>Как добавить русский перевод рецептов</summary>

После импорта базы выполните:

```sh
python tools/translate_ru.py --install --setup --limit 100
```

Команда установит переводчик в отдельное окружение, скачает модель и переведёт до 100 рецептов. Для всей базы замените `--limit 100` на `--all`. Перевод можно прервать и продолжить той же командой. Готовые переводы сохраняются на компьютере.

</details>

Данные рецептов взяты из набора **Food.com Recipes and Reviews**, справочные значения КБЖУ для добавок — из **USDA SR28**.
